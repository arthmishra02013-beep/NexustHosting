# NexusHosting

Standalone Next.js starter built from the supplied NexusHosting specification.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Current scope

- NexusHosting dark hosting UI
- 7 AMD EPYC Minecraft plans
- NPR / INR toggle using the same numeric prices
- Plan detail pages
- Add to cart
- Cart
- Client Area sign in/sign up UI
- Checkout login gate
- Discord support link

Authentication and payments are intentionally local/demo for this first version. They can be connected to Supabase and a payment provider after the UI is approved.
